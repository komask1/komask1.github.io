登录前准备指南

Autodesk ID 账号注册

如果您是首次使用 Maya，必须先注册 Autodesk ID。该账号与您的 Autodesk 软件许可绑定，用于登录 Autodesk 门户。

网络环境要求

玛雅登录和许可激活需要稳定的互联网连接。某些企业网络可能限制特定端口或 IP 地址。

  • 检查防火墙设置
  • 确保使用官方 Autodesk 服务器域名
  • 关闭 VPN（可能导致连接失败）

常见登录问题 (FAQ)

登录时提示“用户名或密码错误”怎么办？
请首先确认您输入的用户名和密码是否正确。注意区分大小写。如果多次尝试失败，建议点击“忘记密码”通过绑定的邮箱重置密码。如果确认无误仍无法登录，可能是账号被锁定或存在安全风险，请联系 Autodesk 支持。
为什么软件提示“许可证验证失败”？
许可证验证失败通常是因为网络无法连接到 Autodesk 许可服务器，或者您的订阅已过期。请检查网络连接，确保可以访问 Autodesk 的许可服务器。如果是企业网络，请咨询 IT 管理员是否限制了对许可端口的访问。
如何切换登录账号（多用户切换）？
在登录页面点击右上角的“切换账户”或“注销”按钮。软件会断开当前连接，您可以输入新的 Autodesk ID 进行登录。注意，同一时间只能有一个账号激活 Maya 许可证。
教育版用户如何登录？
教育版用户可以使用学校提供的 Autodesk ID 登录。登录成功后，在许可激活向导中选择“教育许可”即可激活免费版。请务必使用学校官方邮箱注册的 ID。
